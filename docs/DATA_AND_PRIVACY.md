# データとプライバシー

## 取り扱う可能性があるデータ

- 氏名、車番、Meet参加ID
- 点呼日時、質問、回答、判定、異常フラグ
- 健康状態、酒気、車両状態に関する回答
- 会社への伝達事項
- 録音音声
- 操作、監視、クラスタ、障害ログ

これらは個人情報または業務上の機密情報になり得ます。

## 保存方針

- 録音は14か月保持し、月単位で削除する設計
- 削除処理は点呼中に実行しない
- DB、録音、ログはGitへ登録しない
- NAS同期は確定データを対象とし、リアルタイム推論バッファをNASで直接処理しない
- バックアップにも本番と同等のアクセス制御と保存期限を適用する

## アクセス制御

- 管理UIは信頼できるLAN内に限定する
- 運用管理者、監査担当者、保守担当者の権限を分ける
- Open WebUI、NAS、Google、SMTPの認証情報を個人間で共有しない
- 画面共有、ログ提供、Issue登録時に氏名、車番、Meet URL、ID、IPをマスクする

## 録音

録音を開始する前に、組織の規程、法令、就業規則、本人への通知または同意要件を確認してください。録音の利用目的を点呼確認、監査、障害調査など必要な範囲へ限定し、目的外利用を避けます。

## 削除と開示

削除依頼、訂正、監査、事故調査へ対応できるよう、データの所在、保存期間、バックアップ、削除処理、操作ログを文書化してください。Git履歴へ誤って個人情報を登録した場合は、認証情報と同様に公開範囲を確認し、履歴修正だけでなくキャッシュや複製先も調査します。
