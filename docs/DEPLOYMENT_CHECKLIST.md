# 本番導入チェックリスト

## 導入前

- [ ] 本番利用に関する責任者と運用管理者を決めた
- [ ] 法令上必要な点呼を本システムだけで代替しない運用にした
- [ ] 録音、氏名、車番、健康情報の利用目的とアクセス権を決めた
- [ ] 録音の14か月保持と月次削除を組織方針として確認した
- [ ] Google Meet、録音、音声合成、利用モデルの規約を確認した

## ホスト

- [ ] Docker Desktop、WSL2、NVIDIAドライバーが正常
- [ ] `docker info` と `nvidia-smi` が成功
- [ ] Dockerへ十分なCPU、メモリ、ディスクを割り当てた
- [ ] Windowsの時刻とタイムゾーンが正しい
- [ ] 不要なインターネット公開ポートがない

## 設定

- [ ] `.env.example` から `.env` を作成
- [ ] `ADMIN_TOKEN` と `CHROME_GUI_PASSWORD` をランダム生成
- [ ] 主系・待機系で異なる `CLUSTER_NODE_ID` を設定
- [ ] GPU容量に合うLLMとWhisper計算型を設定
- [ ] NAS認証をソースへ直書きしていない
- [ ] SMTPやOpen WebUIの秘密情報を共有資料へ記載していない

## NAS・冗長化

- [ ] 両PCから共有領域を読み書きできる
- [ ] 主系と待機系のハートビートが管理UIに表示される
- [ ] 同一セッションを二台が同時実行しない
- [ ] 車番・氏名、シナリオ、設定、結果の同期を確認
- [ ] NAS停止時の運用と復旧手順を決めた

## 点呼試験

- [ ] 車番の数字、英字、似た音、言い直し
- [ ] 氏名、Meet ID、過去履歴の照合
- [ ] 肯定、否定、無音、聞き取れない回答
- [ ] 酒気、体調、車両異常、安全語
- [ ] 会社伝達事項なし／あり／訂正／複数事項
- [ ] BOT発話中の割込みと自己音声除外
- [ ] 複数参加者の同時入室、順次点呼、途中退出
- [ ] Google Meet切断、Whisper停止、LLM停止
- [ ] 同一質問のループが発生しない

## データ

- [ ] 管理UIで録音を再生できる
- [ ] DBとDockerボリュームのバックアップを取得
- [ ] 別環境で復元試験を実施
- [ ] 月次削除が点呼中に実行されない
- [ ] 削除後のログと容量を確認

## 本番開始判定

- [ ] 管理者が異常回答を確認できる
- [ ] フォールバックモードへ切り替えられる
- [ ] 主系停止時に待機系で新規点呼を開始できる
- [ ] 連絡先、障害記録、停止判断、復旧責任者を決めた
- [ ] 変更前へ戻す手順を確認した
